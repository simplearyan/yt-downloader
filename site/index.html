FAQ

Questions

“Windows protected your PC” — what is that?

SmartScreen flags installers that aren't code-signed yet. It's the publisher that's unrecognized, not the app. Click More info → Run anyway to install. Code signing is on the roadmap — once it's live, the warning disappears.

Do I need yt-dlp or ffmpeg?

Downloads are powered by yt-dlp and ffmpeg. When running from source, install them with winget install yt-dlp and winget install ffmpeg.

Is it really free?

Yes — free and open source, forever. No account, no ads, no download limits.

Why not a web downloader like vidssave or y2mate?

Those re-encode videos on their servers with cheap settings that corrupt the seek table — files freeze and skip in editors. This app pulls the original streams, so seeking is perfect.

Which Windows versions are supported?

Windows 10 and 11 (64-bit). WebView2 — required by the app — is preinstalled on both.
